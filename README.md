## 2. 현재 ISP 회선 규격 역산

### 2.1 산출 근거

| 계산 항목 | 값 |
|-----------|-----|
| 동시 접속 학생 수 | 500명 |
| 1인당 현재 속도 | 20Mbps |
| **사용 중인 총 대역폭** | **500 x 20Mbps = 10,000Mbps = 10Gbps** |

### 2.2 ISP 회선 추정

| 외부 회선 | 동시 500명 시 1인당 | 동시 250명 시 1인당 | 평가 |
|-----------|---------------------|---------------------|------|
| **1Gbps** | 2Mbps | 4Mbps | X 20Mbps 불가 |
| **10Gbps** | **20Mbps** | 40Mbps | O 현재와 일치 |

> **결론: 현재 외부 ISP 회선은 10Gbps 전용회선으로 추정됩니다.**

## 4. 현재 인프라의 문제점

| 순위 | 문제 | 원인 | 영향 |
|------|------|------|------|
| 1 | **동별 백본 병목** | 1Gbps / 200명 = 5Mbps | 피크 시 체감 속도 급락 |
| 2 | **ISP 회선 포화** | 10Gbps shared | 동시 접속 증가 시 속도↓ |
| 3 | **이중화 없음** | 단일 ISP | 장애 시 전체 서비스 중단 |
| 4 | **QoS 미적용** | 트래픽 관리 부재 | 특정 사용자 독점 가능 |

## 9. 최종 권장 사항

1. **즉시 조치**: 동별 백본 1Gbps -> 10Gbps 업그레이드 (가장 시급)
2. **단기 계획**: ISP 회선 20Gbps 이상 증설
3. **이중화 구성**: 최소 2개 ISP 사용으로 장애 대응
4. **QoS 도입**: 교육용 트래픽 우선 처리
5. **정기 모니터링**: 대역폭 사용률 주간/월간 점검
